In hàng nghìn hóa đơn PDF theo đúng thứ tự danh sách Excel, không lẫn, không sót

Cập nhật 03/11/2026 · Đốm – Quản trị tử tế

Tóm tắt nhanh

  • Chọn cả loạt file PDF rồi bấm in, máy in không giữ thứ tự: xấp giấy phải xếp lại bằng tay, khó biết tờ nào bị thiếu.
  • Công cụ khớp từng file PDF với từng dòng danh sách Excel theo ký hiệu, số hóa đơn, MST người bán; tên file lộn xộn thì đọc chữ trong file.
  • Báo hóa đơn thiếu file, file không có trong danh sách, file trùng, bản scan; xuất Excel đối chiếu.
  • Ghép thành từng lô PDF đúng thứ tự, có số thứ tự ở góc trang; file xử lý ngay trên máy, không gửi lên máy chủ.
  • Mới (bản 1.2.0): đổi tên hàng loạt file PDF theo dạng STT_YYMM_Ký hiệu mẫu số_Ký hiệu hóa đơn_MST người bán_Số hóa đơn_Tên công ty để gõ tìm nhanh trên máy, lưu vào thư mục hoặc tải 1 file nén.

In hóa đơn PDF hàng loạt theo danh sách dùng miễn phí, chạy ngay trên trình duyệt máy tính, dữ liệu không gửi lên máy chủ.

Vì sao in nhiều file PDF một lúc hay bị lẫn?

Khi chọn hàng trăm, hàng nghìn file PDF rồi bấm in, mỗi file là một lệnh in riêng. File nhỏ xử lý nhanh in trước, file nặng in sau, file lỗi bị bỏ qua mà không báo. Kết quả là xấp giấy không theo thứ tự bảng kê, phải ngồi xếp lại và rất khó biết hóa đơn nào chưa có bản in. Ngoài ra cùng một số hóa đơn (ví dụ số 123) có thể của nhiều người bán khác nhau, chỉ nhìn số hóa đơn thì dễ xếp nhầm.

Cách làm bằng công cụ

  1. Nạp file PDF: chọn nhiều file, cả thư mục hoặc file ZIP chứa PDF (kéo thả được). Nạp thêm nhiều lần cũng được, file trùng đường dẫn tự bỏ. Thư mục có sẵn file Excel danh sách thì công cụ tự nhận; có từ 2 file Excel trở lên thì công cụ chọn file khớp nhiều hóa đơn nhất và cho đổi sang file khác.
  2. Nạp danh sách: chọn file Excel (.xlsx) hoặc CSV đã sắp theo thứ tự muốn in, ví dụ bảng kê tải từ cổng thuế hoặc xuất từ phần mềm kế toán. Công cụ tự tìm dòng tiêu đề và cột số hóa đơn, ký hiệu, MST người bán; chọn lại được nếu nhận sai. File có nhiều trang tính (ví dụ mỗi tháng một trang) thì tick các trang cần dùng – có nút Chọn tất cả / Bỏ chọn tất cả – và giữ, kéo thả để sắp thứ tự trang; công cụ gộp theo thứ tự đó, số thứ tự chạy liền.
  3. Khớp & kiểm tra: bấm Khớp. Công cụ khớp theo tên file trước (ví dụ 1C26TAA_00000123.pdf); file nào tên không đủ thông tin thì đọc chữ trong file. Kết quả chia nhóm: khớp chắc chắn, khớp theo số hóa đơn (nên xem lại), thiếu file, file chưa khớp, file trùng.
  4. Gán tay, lưu đối chiếu: dòng thiếu file có ô chọn để gán file chưa khớp; tải Excel đối chiếu để lưu hồ sơ.
  5. Ghép file để in: chọn số hóa đơn mỗi lô (50, 100, 200, 500 hoặc 1 file), bật số thứ tự góc trang, in 2 mặt, trang báo thiếu hóa đơn nếu cần, bấm Ghép file. Mở từng lô và in bằng một lệnh, in xong lô này mới in lô sau.

Đổi tên file & lưu file mềm để tra cứu

File hóa đơn tải hàng loạt từ phần mềm thường có tên dính liền, không dấu, ví dụ 0123456789_1_C26TDS_00000123_25102026_congtytnhhdomsang.pdf. Gõ số hóa đơn hay tên công ty vào ô tìm kiếm của Windows thường không ra, phải kéo lên kéo xuống để tìm. Bản in chỉ để lưu trữ, còn khi cần tra cứu thì vẫn tìm trên file mềm là chính.

  1. Khớp xong danh sách (bước 1–3 ở trên), sang Bước 4 – In & tải về, kéo xuống mục Lưu file mềm. Không cần in thì ở bước Ghép file bấm Chỉ lưu file mềm.
  2. Chọn các phần trong tên file: mặc định là STT_YYMM_Ký hiệu mẫu số_Ký hiệu hóa đơn_MST người bán_Số hóa đơn_Tên công ty. Tích hoặc bỏ từng phần, giữ và kéo thả từng dòng (hoặc bấm mũi tên ↑↓) để đổi thứ tự; thêm được ngày hóa đơn hoặc chữ tự nhập. Đổi được dấu nối (gạch dưới, gạch ngang, dấu chấm, dấu cách).
  3. Chọn cách viết tên công ty: mặc định giữ nguyên có dấu và dấu cách; tích Bỏ dấu tiếng Việt và/hoặc Bỏ dấu cách nếu quen gõ không dấu. Khung Xem trước tên mới hiện ngay kết quả.
  4. Lưu: bấm Lưu vào một thư mục (Chrome, Edge) để ghi thẳng các file đã đổi tên vào thư mục chọn, hoặc Tải file nén (ZIP). Kèm theo là file Excel đối chiếu có cột "Tên file mới".

  • Số thứ tự trong tên trùng với số in ở góc tờ hóa đơn khi ghép lô, nên tìm trên máy và tìm trong tủ hồ sơ theo cùng một số.
  • Năm tháng (YYMM) lấy từ ngày hóa đơn: hóa đơn ngày 30/09/2026 là 2609.
  • File trùng, có mật khẩu, không có trong danh sách vẫn được tải kèm, gắn chữ đầu tên để biết ngay: Trùng_0024_… (bản tải 2 lần của hóa đơn STT 24), Mật khẩu_… (file có mật khẩu, không đọc được nội dung), Không trong DS_… hoặc Chưa khớp_… (bỏ tích "Kèm file không có trong danh sách" nếu không cần).
  • Tờ khai hải quan nhập khẩu trong danh sách (số tờ khai 12 chữ số, không có ký hiệu, MST) vẫn giữ đúng số thứ tự; có file PDF tờ khai mà tên hoặc nội dung chứa số tờ khai thì công cụ khớp và đổi tên luôn.
  • Ký tự Windows không cho dùng trong tên file (như / : * ? " < > |) được đổi thành dấu "-"; tên quá dài thì cắt bớt phần tên công ty; 2 file trùng tên thì thêm (2), (3). Dòng thiếu file PDF được bỏ qua.

Lưu ý khi tải file nén: Windows có thể chặn mở file ngay bên trong file nén tải từ trình duyệt. Bấm chuột phải vào file nén → Extract All (Giải nén tất cả) rồi mở trong thư mục vừa giải nén. Dùng Chrome hoặc Edge thì nên chọn Lưu vào một thư mục.

Công cụ khớp file với danh sách theo cách nào?

  • Tên file có ký hiệu và số hóa đơn đứng liền nhau (kiểu tên file tải từ cổng thuế) được coi là khớp chắc chắn; có thêm MST người bán thì càng chắc.
  • Tên file chỉ có số hóa đơn: chỉ khớp khi số đó duy nhất trong danh sách và được đánh dấu "nên xem lại"; công cụ đọc thêm chữ trong file để xác nhận.
  • Hai file cùng khớp một hóa đơn: file sau được báo là trùng, bản có đuôi "(1)", "Copy" xếp sau bản gốc. Dòng lặp lại trong danh sách không in lại.
  • Số thứ tự in ở góc trên bên phải mỗi trang dạng 0001/2000 · C26TAA-123, đặt đúng góc kể cả trang xoay ngang.

Lưu ý: bản scan chỉ có hình ảnh thì công cụ không đọc được chữ, cần tên file có ký hiệu và số hóa đơn, hoặc gán tay. File PDF có mật khẩu hoặc bị hỏng sẽ được báo để in riêng. Chọn cả thư mục và lưu vào thư mục chạy tốt nhất trên Chrome, Edge.

Câu hỏi thường gặp

Không có danh sách Excel thì có dùng được không?

Có. Không nạp danh sách thì công cụ xếp theo đường dẫn và tên file (số tự nhiên: 2 trước 10), vẫn ghép lô và đánh số thứ tự.

2.000 file thì mất bao lâu?

Phần lớn thời gian là đọc chữ trong các file có tên không đủ thông tin; file đặt tên chuẩn có ký hiệu và số hóa đơn thì khớp gần như tức thì. Có thanh tiến độ và nút Dừng.

File có bị gửi lên mạng không?

Không. File PDF và danh sách được xử lý ngay trên máy của anh/chị; có bản tải về dùng không cần mạng.

Danh sách có tờ khai nhập khẩu thì số thứ tự có bị lệch không?

Không. Từ bản 1.2.1, dòng tờ khai hải quan (số tờ khai 12 chữ số, không có số hóa đơn, MST) vẫn giữ số thứ tự của nó; nếu có file PDF tờ khai thì công cụ khớp theo số tờ khai, không có thì báo thiếu file.

Đổi tên file có làm thay đổi file gốc trên máy không?

Không. Công cụ tạo bản sao đã đổi tên (lưu vào thư mục chọn hoặc file nén), file gốc giữ nguyên tên và vị trí.

Bảng kê có nhiều trang tính theo tháng thì làm thế nào?

Công cụ liệt kê tất cả trang tính kèm số hóa đơn từng trang, tick sẵn các trang có hóa đơn. Bấm Bỏ chọn tất cả rồi tick các tháng cần dùng; công cụ gộp theo thứ tự trang tính, đổi thứ tự bằng cách giữ và kéo thả (hoặc nút mũi tên).

Có tốn phí không?

Không, công cụ dùng miễn phí.
