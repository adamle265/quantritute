In hàng nghìn hóa đơn PDF theo đúng thứ tự danh sách Excel, không lẫn, không sót

Cập nhật 02/11/2026 · Đốm – Quản trị tử tế

Tóm tắt nhanh

  • Chọn cả loạt file PDF rồi bấm in, máy in không giữ thứ tự: xấp giấy phải xếp lại bằng tay, khó biết tờ nào bị thiếu.
  • Công cụ khớp từng file PDF với từng dòng danh sách Excel theo ký hiệu, số hóa đơn, MST người bán; tên file lộn xộn thì đọc chữ trong file.
  • Báo hóa đơn thiếu file, file không có trong danh sách, file trùng, bản scan; xuất Excel đối chiếu.
  • Ghép thành từng lô PDF đúng thứ tự, có số thứ tự ở góc trang; file xử lý ngay trên máy, không gửi lên máy chủ.

In hóa đơn PDF hàng loạt theo danh sách dùng miễn phí, chạy ngay trên trình duyệt máy tính, dữ liệu không gửi lên máy chủ.

Vì sao in nhiều file PDF một lúc hay bị lẫn?

Khi chọn hàng trăm, hàng nghìn file PDF rồi bấm in, mỗi file là một lệnh in riêng. File nhỏ xử lý nhanh in trước, file nặng in sau, file lỗi bị bỏ qua mà không báo. Kết quả là xấp giấy không theo thứ tự bảng kê, phải ngồi xếp lại và rất khó biết hóa đơn nào chưa có bản in. Ngoài ra cùng một số hóa đơn (ví dụ số 123) có thể của nhiều người bán khác nhau, chỉ nhìn số hóa đơn thì dễ xếp nhầm.

Cách làm bằng công cụ

  1. Nạp file PDF: chọn nhiều file, cả thư mục hoặc file ZIP chứa PDF (kéo thả được). Nạp thêm nhiều lần cũng được, file trùng đường dẫn tự bỏ.
  2. Nạp danh sách: chọn file Excel (.xlsx) hoặc CSV đã sắp theo thứ tự muốn in, ví dụ bảng kê tải từ cổng thuế hoặc xuất từ phần mềm kế toán. Công cụ tự tìm dòng tiêu đề và cột số hóa đơn, ký hiệu, MST người bán; chọn lại được nếu nhận sai.
  3. Khớp & kiểm tra: bấm Khớp. Công cụ khớp theo tên file trước (ví dụ 1C26TAA_00000123.pdf); file nào tên không đủ thông tin thì đọc chữ trong file. Kết quả chia nhóm: khớp chắc chắn, khớp theo số hóa đơn (nên xem lại), thiếu file, file chưa khớp, file trùng.
  4. Gán tay, lưu đối chiếu: dòng thiếu file có ô chọn để gán file chưa khớp; tải Excel đối chiếu để lưu hồ sơ.
  5. Ghép file để in: chọn số hóa đơn mỗi lô (50, 100, 200, 500 hoặc 1 file), bật số thứ tự góc trang, in 2 mặt, trang báo thiếu hóa đơn nếu cần, bấm Ghép file. Mở từng lô và in bằng một lệnh, in xong lô này mới in lô sau.

Công cụ khớp file với danh sách theo cách nào?

  • Tên file có ký hiệu và số hóa đơn đứng liền nhau (kiểu tên file tải từ cổng thuế) được coi là khớp chắc chắn; có thêm MST người bán thì càng chắc.
  • Tên file chỉ có số hóa đơn: chỉ khớp khi số đó duy nhất trong danh sách và được đánh dấu "nên xem lại"; công cụ đọc thêm chữ trong file để xác nhận.
  • Hai file cùng khớp một hóa đơn: file sau được báo là trùng, bản có đuôi "(1)", "Copy" xếp sau bản gốc. Dòng lặp lại trong danh sách không in lại.
  • Số thứ tự in ở góc trên bên phải mỗi trang dạng 0001/2000 · C26TAA-123, đặt đúng góc kể cả trang xoay ngang.

Lưu ý: bản scan chỉ có hình ảnh thì công cụ không đọc được chữ, cần tên file có ký hiệu và số hóa đơn, hoặc gán tay. File PDF có mật khẩu hoặc bị hỏng sẽ được báo để in riêng. Chọn cả thư mục và lưu vào thư mục chạy tốt nhất trên Chrome, Edge.

Câu hỏi thường gặp

Không có danh sách Excel thì có dùng được không?

Có. Không nạp danh sách thì công cụ xếp theo đường dẫn và tên file (số tự nhiên: 2 trước 10), vẫn ghép lô và đánh số thứ tự.

2.000 file thì mất bao lâu?

Phần lớn thời gian là đọc chữ trong các file có tên không đủ thông tin; file đặt tên chuẩn có ký hiệu và số hóa đơn thì khớp gần như tức thì. Có thanh tiến độ và nút Dừng.

File có bị gửi lên mạng không?

Không. File PDF và danh sách được xử lý ngay trên máy của anh/chị; có bản tải về dùng không cần mạng.

Có tốn phí không?

Không, công cụ dùng miễn phí.
