Tạo hàng loạt hợp đồng, phiếu lương, giấy chứng nhận từ file mẫu và danh sách Excel

Cập nhật 21/10/2026 · Đốm – Quản trị tử tế

Tóm tắt nhanh

  • Gõ lại cùng một hợp đồng, giấy mời, giấy chứng nhận cho hàng chục người vừa lâu vừa dễ sai tên.
  • Công cụ ghép file mẫu với danh sách Excel, mỗi dòng ra một văn bản (Word, Excel, PDF hoặc ảnh).
  • Không cần biết Mail Merge; file mẫu chưa đánh dấu trường vẫn ghép tay được.

Tạo văn bản hàng loạt dùng miễn phí, chạy ngay trên trình duyệt máy tính, dữ liệu không gửi lên máy chủ.

Mail Merge khó ở đâu?

Mail Merge trong Word làm được việc này nhưng cần thao tác nhiều bước, khó với mẫu PDF hay ảnh (giấy chứng nhận, thư mời thiết kế sẵn), và hay lỗi định dạng số, ngày tháng. Nhiều người chọn cách sửa tay từng bản, dễ sót và sai tên.

Cách làm

  1. Tải file mẫu: Word, Excel, PDF hoặc ảnh. Mẫu đã có ký hiệu trường thì công cụ nhận luôn; chưa có thì công cụ hướng dẫn tạo hoặc cho ghép tay.
  2. Tải file danh sách Excel/CSV, mỗi người một dòng. File có nhiều trang tính thì chọn trang lấy dữ liệu.
  3. Ghép trường: kéo cột trong danh sách thả vào đúng chỗ trên mẫu. Với PDF/ảnh, kéo khung quanh chữ cũ, công cụ tự bắt cỡ chữ, kiểu chữ, màu.
  4. Xem thử từng bản, sửa định dạng (thêm số 0 phía trước, giữ nguyên năm, mã số…).
  5. Xuất file: mỗi dòng một file lưu vào thư mục, hoặc gộp thành một file, hoặc nén ZIP.

Câu hỏi thường gặp

Có cần cài phần mềm không?

Không. Công cụ chạy trên trình duyệt Chrome hoặc Edge; có thể tải bản offline 1 file để dùng không cần mạng.

Danh sách của tôi có bị gửi lên mạng không?

Không. File mẫu và danh sách được xử lý ngay trên máy của anh/chị.

Xuất ra PDF được không?

Được. Mẫu Word cũng xuất được PDF (tách từng file hoặc gộp); với mẫu Word, bản PDF dựng dạng ảnh trang nên chữ không chọn được.

Hướng dẫn liên quan

  • Chuyển file XML hóa đơn điện tử sang Excel hàng loạt (bảng kê mua vào, bán ra)
