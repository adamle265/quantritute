Chuyển file XML hóa đơn điện tử sang Excel hàng loạt (bảng kê mua vào, bán ra)

Cập nhật 21/10/2026 · Đốm – Quản trị tử tế

Tóm tắt nhanh

  • File XML là bản gốc của hóa đơn điện tử nhưng khó đọc, không mở thẳng thành bảng được.
  • Thả nhiều file XML hoặc file ZIP vào công cụ → ra 1 file Excel gồm bảng kê mua vào, bán ra, tổng hợp thuế suất, chi tiết hàng hóa.
  • Dữ liệu xử lý ngay trên máy tính của anh/chị, không tải lên máy chủ.

Bộ công cụ hóa đơn thuế dùng miễn phí, chạy ngay trên trình duyệt máy tính, dữ liệu không gửi lên máy chủ.

Vì sao cần chuyển XML sang Excel?

Hóa đơn điện tử có giá trị pháp lý ở file XML. Muốn đối chiếu số liệu, lập bảng kê hay kiểm tra thuế suất, kế toán thường phải mở từng hóa đơn rồi gõ lại vào Excel. Gõ tay vừa lâu vừa dễ sai số, nhất là với hóa đơn nhiều dòng hàng, có chiết khấu hoặc nhiều thuế suất.

Cách làm

  1. Mở công cụ trên máy tính, chọn thẻ XML → Excel.
  2. Thả vào nhiều file XML cùng lúc, hoặc thả nguyên file ZIP tải từ cổng thuế. Có thể thêm hoặc gỡ từng file.
  3. Xem mục Cần xem lại: công cụ báo các hóa đơn lệch tổng, hóa đơn ngoại tệ, hóa đơn bị thay thế/hủy.
  4. Bấm xuất Excel.

File Excel nhận được

SheetNội dung
Bảng kê mua vào / Bảng kê bán raMỗi hóa đơn một dòng, có STT và dòng tổng riêng cho từng chiều.
Tổng hợp thuế suấtGiá trị chưa thuế và tiền thuế theo từng mức thuế suất.
Chi tiết hàng hóaTừng dòng hàng hóa, dịch vụ trên các hóa đơn.

Công cụ xử lý những trường hợp khó thế nào?

  • Hóa đơn trùng (cùng mã số thuế người bán, mẫu, ký hiệu, số) chỉ tính 1 lần.
  • Hóa đơn bị thay thế, bị hủy vẫn liệt kê nhưng ghi "Không" ở cột tính vào tổng.
  • Chiết khấu thương mại: lấy tổng của hóa đơn làm chuẩn, phần chiết khấu trừ đúng vào từng thuế suất.
  • Ngày tháng luôn ở dạng dd/mm/yyyy và là kiểu ngày thật trong Excel, lọc và sắp xếp được.
Dù công cụ đã đối chiếu tổng tiền, anh/chị vẫn nên rà mục "Cần xem lại" trước khi dùng số liệu để kê khai.

Câu hỏi thường gặp

Có giới hạn số file không?

Công cụ chạy trên trình duyệt nên phụ thuộc cấu hình máy; số lượng của một quý thông thường xử lý được trong một lần.

Dữ liệu hóa đơn có bị gửi đi đâu không?

Không. File được đọc và xử lý ngay trên máy của anh/chị.

Có nhập được vào MISA không?

Trong cùng bộ công cụ có thẻ "Tạo file nhập lên Misa" theo mẫu nhập khẩu của MISA AMIS Kế toán. Anh/chị nên nhập thử vài chứng từ trước khi nhập cả kỳ.
