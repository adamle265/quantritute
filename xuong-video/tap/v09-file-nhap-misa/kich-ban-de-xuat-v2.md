# v09 – Tạo sẵn file nhập lên MISA · Kịch bản đề xuất v2 (Cổng 2)

20/10/2026 14:56 · theo góp ý anh: tiêu đề **"TẠO SẴN FILE NHẬP LÊN MISA"** (2 dòng: TẠO SẴN FILE NHẬP / LÊN MISA – đã render), nút thumbnail **"THAO TÁC DỄ DÀNG, NHANH CHÓNG"**, bỏ câu hứa, thêm đoạn "nhiều anh chị kế toán quan tâm – đang tối ưu thêm" (D08).
Đốm dẫn 100% · ước tính **~65s** (mở đầu 5s + thân ~43s + CTA ~10s + kết 7s). D03, D04 rút gọn để bù đoạn mới.

| Đoạn | Cảnh | Phụ đề (chữ gốc) |
|---|---|---|
| D01 | Danh sách 2 file đã nạp → bấm thẻ 5 | Từ chính những hóa đơn đã nạp, Đốm tạo sẵn file để nhập lên MISA. Anh chị bấm sang thẻ 5. |
| D02 | ① Mua vào (61) / Bán ra (80) + dòng MST | Công cụ tự tách mua vào, bán ra theo mã số thuế doanh nghiệp. |
| D03 | ② Nhà cung cấp → Tải lên danh mục → Xuất Excel danh mục NCC | Nhà cung cấp trên hóa đơn được gom sẵn. Tải lên danh mục từ MISA để tự điền mã, hoặc xuất Excel danh mục cho nhà cung cấp mới. |
| D04 | ③ Bảng hàng hóa, cột Loại + nhãn "gợi ý" | Hàng hóa, dịch vụ hiện từng dòng, kèm gợi ý loại. Ăn uống, xăng dầu, phí ngân hàng được gợi ý là nghiệp vụ khác, không cần sinh mã hàng. |
| D05 | Ô TK → nút ✓ Xác nhận | Anh chị rà lại, chọn tài khoản, rồi bấm dấu tích xác nhận. |
| D06 | ④ Xuất file: 3 file mua vào → Bán ra → 2 file + Tải tất cả | Cuối cùng là các file đúng mẫu nhập khẩu của MISA: mua hàng trong nước, mua dịch vụ, nghiệp vụ khác, bán hàng, bán dịch vụ. Tải từng file, hoặc cả gói ZIP. |
| D07 | Khung đỏ thông tin còn thiếu + ghi chú | Ô còn thiếu thông tin, Đốm liệt kê bên dưới. Nên nhập thử vài chứng từ trước khi nhập cả kỳ. |
| D08 *(mới)* | Đốm cỡ lớn + toàn cảnh thẻ 5 | Tính năng này được nhiều anh chị kế toán quan tâm, vì giúp bớt thời gian nhập tay và hạn chế sai sót khi tự làm. Đốm đang tiếp tục tối ưu, để phần này dễ dùng và tiện hơn nữa. |
| D09 | Dòng cam kết (chép giọng D13 v07) | Công cụ hoàn toàn miễn phí, xử lý ngay trên máy của anh chị, không gửi hóa đơn ra ngoài. |
| D10 | Đốm cảm ơn + nút bio (chép giọng D14 v07) | Link dùng thử, Đốm để ở bio của kênh. Anh chị dùng thử, và góp ý để Đốm hoàn thiện thêm nhé! |
