# v07 – Từ file ZIP ra bảng kê Excel · Kịch bản đề xuất v1 (20/10/2026, chờ anh duyệt Cổng 2)

Đốm dẫn 100%. Dữ liệu: ZIP mua vào tải ở v06 (61 HĐ) + ZIP bán ra Q3 (80 HĐ) – đều là dữ liệu đã đổi tên (MST 9876543210). Đã chạy thật thẻ 2 bản 1.5.4 để lấy số.

## Phát hiện khi chạy thử
- File ZIP của thẻ 1 ĐÃ CÓ sẵn Bang-ke-hoa-don.xlsx 5 sheet, giống bản thẻ 2 xuất ra (chỉ mua vào) → nếu video chỉ "kéo ZIP → xuất Excel" thì người xem sẽ hỏi "để làm gì".
- Giá trị riêng của thẻ 2: gộp nhiều file (mua vào + bán ra → tách 2 sheet bảng kê), nhận XML lẻ / gói tải tay, tự bỏ trùng, mục "Cần xem lại", tải XML bổ sung, xem nhanh trên màn hình.
- Số thật: mua vào 61 HĐ / 232 dòng hàng; mua + bán 141 HĐ / 313 dòng; Cần xem lại 7 (đều là "Không có XML": 3 Techcombank, 3 Điện lực Phú Thọ, 1 FPT). Dữ liệu không có HĐ hủy/thay thế → chỉ nói, không dựng giả. Thêm lại 1 XML đã có → báo "Trùng… đã bỏ, chỉ tính 1 lần", tổng giữ nguyên.

## Lời Đốm (phụ đề chữ gốc; Vbee đọc phiên âm)
| Đoạn | Hình | Lời |
|---|---|---|
| D01 | Thư mục có file ZIP từ video trước | Ở video trước, anh chị đã tải được hóa đơn cả quý trong một file ZIP. |
| D02 | Mở ZIP thấy sẵn file Bang-ke → mở công cụ, thẻ 2 | Trong file đã có sẵn một bảng kê nhanh. Còn thẻ 2 giúp anh chị gộp nhiều file, kiểm tra từng hóa đơn, rồi mới xuất Excel. |
| D03 | ① Kéo 2 file ZIP (mua vào + bán ra) vào ô | Bước 1, mở thẻ "XML → Excel", kéo file ZIP mua vào và file ZIP bán ra vào cùng lúc. |
| D04 | Viền sáng dòng hướng dẫn + ô MST tự điền | Công cụ nhận cả file ZIP tải từ thẻ 1, file XML lẻ, hoặc gói ZIP tải tay từ trang thuế. MST doanh nghiệp tự điền, để tự tách mua vào và bán ra. |
| D05 | ② Thẻ số liệu | Bước 2, xem nhanh số liệu: 141 hóa đơn, 313 dòng hàng hóa, kèm tổng tiền ngay trên màn hình. |
| D06 | ③ Mục "Cần xem lại (7)" | Bước 3, xem mục "Cần xem lại trước khi dùng số liệu". Ở ví dụ này có 7 hóa đơn điện, ngân hàng, viễn thông mà cổng thuế không lưu XML gốc: bảng kê vẫn có số tổng, chỉ thiếu chi tiết hàng hóa. |
| D07 | Viền sáng nút "Tải lên file XML bổ sung" | Người bán đã gửi file XML qua email, thì anh chị bấm "Tải lên file XML bổ sung": hóa đơn được bổ sung đầy đủ, cảnh báo tự mất. |
| D08 | + Thêm file → 1 XML đã có → dòng "Trùng" | Hóa đơn bị hủy, bị thay thế vẫn được liệt kê nhưng không cộng vào tổng. Còn hóa đơn trùng thì tự bỏ: Đốm thêm lại một file đã có, công cụ báo trùng và chỉ tính một lần. |
| D09 | ④ Bấm lần lượt 6 bảng | Bước 4, xem từng bảng: bảng kê mua vào, bảng kê bán ra, chi tiết hàng hóa, tổng hợp thuế suất, gộp một bảng, và tra cứu mẫu người bán. |
| D10 | Bảng Tổng hợp thuế suất | Bảng tổng hợp thuế suất gom sẵn tiền hàng, tiền thuế theo từng mức thuế, tiện đối chiếu khi kê khai. |
| D11 | Bấm "Xuất Excel" → mở file (khung Excel mô phỏng hiển thị đúng file xuất ra) → bấm mũi tên lọc | Bấm "Xuất Excel": file có đủ các bảng, cột số đã định dạng, ngày dạng ngày/tháng/năm, và có sẵn bộ lọc. |
| D12 | Thu khung, chuyển sang kết | Video sau, Đốm sẽ chỉ anh chị dùng chính các file này để lập số liệu tờ khai thuế GTGT. |
