Có cả trăm file XML hóa đơn mua vào, bán ra, mà vẫn phải mở từng file chép sang Excel?

Đốm hướng dẫn chuyển đổi hàng loạt XML sang file Excel, kèm kiểm tra từng hóa đơn:
① Kéo thả cùng lúc file ZIP mua vào, bán ra (nhận cả XML lẻ, gói ZIP tải tay từ trang thuế)
② Xem nhanh số hóa đơn, dòng hàng hóa, tổng tiền
③ Mục "Cần xem lại": hóa đơn không có XML gốc, hóa đơn trùng (tự bỏ), hóa đơn bị hủy/thay thế (không cộng vào tổng)
④ Xem từng bảng: bảng kê mua vào, bán ra, chi tiết hàng hóa, tổng hợp thuế suất, gộp một bảng, tra cứu mẫu người bán
