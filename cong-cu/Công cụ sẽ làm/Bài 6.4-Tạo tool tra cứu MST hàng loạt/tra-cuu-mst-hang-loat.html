Bỏ qua (đã đủ)
⏳ API đang giới hạn tốc độ (HTTP 429) — công cụ đã tạm dừng để tránh bị chặn lâu hơn. Hãy chờ khoảng 1–2 phút rồi bấm "▶ Tiếp tục". Sau đó bấm "↻ Tra lại các dòng lỗi" để tra nốt các dòng bị 429. Nếu vẫn hay gặp lỗi này, tăng "Nghỉ giữa 2 lần tra" lên 2000–3000 ms nhé.
⚠️ Nhiều lỗi kết nối liên tiếp — có thể trình duyệt/môi trường đang chặn gọi API (lỗi CORS). Cách khắc phục: tải file HTML của công cụ này về máy (nút tải ở góc cửa sổ artifact), mở trực tiếp bằng Chrome/Edge rồi chạy lại. Nếu vẫn bị chặn, hãy nhắn cho Claude để nhận bản Python chạy trên máy — hoạt động 100%.
