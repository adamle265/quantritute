Tra cứu mã số thuế hàng loạt PRO

Dùng được với mọi bố cục file Excel: tải file lên, công cụ tự nhận diện cột MST, bạn chọn cột muốn điền kết quả (Tên người nộp thuế, Địa chỉ, Cơ quan thuế, Trạng thái…) rồi bấm chạy. Dữ liệu và định dạng gốc được giữ nguyên.

📖 Hướng dẫn nhanh (dành cho người mới nhận công cụ này)
  1. Tải file Excel (.xlsx) có cột chứa mã số thuế lên khung bên dưới.
  2. Ở bước 2, xem bảng xem trước: cột xanh lá là cột MST, cột vàng là nơi sẽ điền kết quả. Nếu công cụ đoán chưa đúng, bạn chỉnh lại bằng các ô chọn.
  3. Bấm ▶ Bắt đầu tra cứu và chờ chạy xong (mỗi mã mất khoảng 1–2 giây).
  4. Bấm ⬇ Tải file Excel hoàn chỉnh để nhận file đã điền đủ thông tin.
