## GIAO DIỆN: 4 BƯỚC, có thanh chỉ bước ở trên cùng

BƯỚC 2 – CHỌN CỘT KHÓA & KIỂM TRA

BƯỚC 3 – CHỌN KIỂU GHÉP & CỘT
- 7 thẻ lựa chọn. Mỗi thẻ có hình 2 vòng tròn giao nhau (vẽ bằng SVG) tô màu phần được lấy, tên dễ hiểu và 1 dòng ví dụ:
  1. Giữ đủ File A, lấy thêm thông tin từ File B – VD: gắn tên khách hàng vào từng đơn hàng
  2. Giữ đủ File B, lấy thêm thông tin từ File A
  3. Chỉ lấy dòng có ở cả 2 file
  4. Gộp tất cả, không bỏ sót dòng nào
  5. Dòng có ở A nhưng B không có – VD: đơn hàng mang mã khách không có trong danh mục
  6. Dòng có ở B nhưng A không có – VD: khách hàng chưa phát sinh đơn nào
  7. Báo cáo tra soát toàn diện (thẻ nổi bật hơn) – gộp tất cả, gắn trạng thái từng dòng và so sánh giá trị
- Nút "Đổi chỗ A ↔ B".
- Chọn cột muốn lấy từ File A và File B (dạng ô tích, có "Chọn tất cả"). Cột trùng tên giữa 2 file tự thêm đuôi " (A)" và " (B)".

- Nút lớn "Chạy".

BƯỚC 4 – KẾT QUẢ

## QUY TẮC KẾT QUẢ

## YÊU CẦU KỸ THUẬT (QUAN TRỌNG)
- Đọc file bằng SheetJS, xuất file bằng ExcelJS (để tô màu được), tải thư viện từ cdnjs.
- TÁCH RIÊNG giao diện và phần xử lý. Toàn bộ xử lý dữ liệu nằm trong một đối tượng tên là `engine`, gồm các hàm bất đồng bộ (async), nhận vào và trả về dữ liệu dạng JSON:
  + engine.loadFile(slot, file) → danh sách sheet
  + engine.loadSheet(slot, sheetName, headerRow) → số dòng, danh sách cột, 5 dòng xem trước, dòng tiêu đề tự dò
  + engine.loadSampleData() → nạp dữ liệu mẫu
  + engine.suggestKeys() → các cặp cột gợi ý kèm tỉ lệ trùng
  + engine.checkKeys(config) → kết quả kiểm tra sức khỏe dữ liệu
  + engine.runMerge(config) → thống kê và 100 dòng xem trước
  + engine.exportExcel(config) → tải file về
  Giao diện CHỈ được làm việc với dữ liệu thông qua các hàm này, không truy cập dữ liệu trực tiếp. Mục đích: sau này tôi sẽ thay toàn bộ `engine` bằng Python chạy ở máy chủ mà không phải sửa giao diện.
- Thuật toán ghép dùng bảng băm (Map), không dùng vòng lặp lồng nhau.
- Có thanh tiến trình, giao diện không bị đơ khi đang xử lý.
- Không dùng localStorage hoặc sessionStorage.
- Mọi nhãn, thông báo, lỗi đều bằng tiếng Việt, dễ hiểu.

## CÔNG NGHỆ
- Flask làm máy chủ.
- pandas để xử lý dữ liệu. Đọc file Excel (.xlsx, .xls) bằng engine "calamine" (thư viện python-calamine) cho nhanh. Đọc CSV tự nhận bảng mã (utf-8, utf-8-sig, windows-1258, cp1252) và dấu phân cách (dấu phẩy hoặc chấm phẩy).
- Xuất Excel bằng xlsxwriter. Tô màu theo trạng thái bằng định dạng có điều kiện (conditional formatting) để ghi nhanh với file lớn.

## HIỆU NĂNG
