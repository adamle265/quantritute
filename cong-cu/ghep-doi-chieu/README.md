## Nguồn gốc & chỗ khác bản gốc
- Bản gốc: `Công cụ sẽ làm/Bài 6.11-Xây dựng tool ghép và đối chiếu file/` (prompt artifact → app Python/Flask). File gốc giữ nguyên, chỉ chép sang.
- Video bài 6.11 cho thấy: bản artifact không chạy nổi file 200k dòng nên phải chuyển sang Python (người dùng phải cài Python, máy Mac bị chặn file .command); tiến trình đọc file đứng 0%; kiểu 7 lỗi khi file có sẵn cột "Trạng thái"; sổ kế toán có dòng "Cộng", chữ ký cuối sổ bị tính là dữ liệu.
- **Bản web viết lại phần xử lý chạy ngay trong trình duyệt** (Web Worker), giữ nguyên 4 bước, 7 kiểu ghép, tên hàm `engine.*` như prompt gốc:
  - Bộ đọc .xlsx tự viết (giải nén bằng fflate, đọc thẳng XML) – 200.000 dòng × 14 cột đọc ~3,5 giây; .xls/.xlsb dùng SheetJS 0.18.5 nạp khi cần (`app/xlsx.full.min.js`, bản offline lấy từ cdnjs); CSV tự nhận UTF-8/Windows-1258, dấu `,` `;` tab.
  - Ghép bằng bảng băm, kết quả lưu dạng chỉ số dòng (không chép dữ liệu) → 200k × 191k ghép 0,1–0,5 giây.
  - Tự ghi file .xlsx (nén từng phần), tô màu bằng định dạng có điều kiện, có bộ lọc, cố định tiêu đề, tách sheet khi vượt 1.048.575 dòng.
- **Nâng cấp anh chọn (21/10):**
  1. Tự bỏ dòng Cộng / Tổng cộng / chữ ký / "Ngày … tháng … năm" cuối bảng, báo rõ đã bỏ dòng nào (chữ đỏ), có ô tắt.
  2. Tự gợi ý cặp cột so sánh ở kiểu 7 (dò giá trị trùng trên 3.000 dòng khớp đầu tiên), hiện tỉ lệ ≈ %.
  3. Kết quả xem đủ theo trang 100 dòng, lọc trạng thái kèm số đếm, tìm kiếm không dấu; bảng **Đối chiếu tổng tiền** (A, B, A − B, tách do dòng lệch / chỉ có ở A / chỉ có ở B, số dòng lệch); Excel có thêm cột số "Chênh lệch <cột>" và bảng tổng tiền ở sheet Tổng hợp.
  4. Lưu / nạp thiết lập (file `thiet-lap-ghep_yyyymmdd.json`): cặp khóa, làm sạch, kiểu ghép, cột, cặp so sánh, sheet + dòng tiêu đề; báo cột không còn trong file mới.
- Khác thêm: gợi ý cột khóa ưu tiên cột ít lặp (mã đơn) hơn cột lặp nhiều (mã khách), bỏ cột số tiền/ngày/cột vài giá trị; kiểu 7 thẻ "Khớp hoàn toàn" không tính dòng lệch; so sánh giá trị lấy từ dữ liệu gốc kể cả khi không chọn cột đó vào kết quả; cột kết quả kiểu 7: Trạng thái → Khóa → Chi tiết lệch → Chênh lệch → cột A → cột B.
- Giao diện: đổi sang màu/chữ chung của web (giấy kem, Lexend, Đốm), bật/tắt theo chế độ tối của máy, nút chuyển bước ở góc trên phải, ngày dd/mm/yyyy, footer có "← Quay lại Bộ công cụ" và link bản Python.
- Bản Python gốc đóng gói nguyên vẹn ở `app/ban-python/Tool_Ghep_Doi_Chieu.zip` (chưa có các nâng cấp trên).
