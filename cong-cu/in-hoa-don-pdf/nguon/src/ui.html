Bước 1 — Tải file

File PDF hóa đơn và file danh sách để xếp thứ tự in. Có thể nạp thêm file nhiều lần.

PDFHóa đơn PDF

Chọn nhiều file, cả thư mục, hoặc file ZIP chứa PDF.

Kéo thả file PDF hoặc cả thư mục vào đâyNhận .pdf và .zip · Hàng nghìn file vẫn chạy được

EXCELDanh sách hóa đơn (để xếp thứ tự in)

Bảng kê tải từ cổng thuế, xuất từ phần mềm kế toán… Thứ tự in = thứ tự dòng trong file. Không có danh sách thì công cụ xếp theo tên file.

Kéo thả file danh sách vào đâyNhận .xlsx, .csv (file .xls cũ: mở bằng Excel, lưu lại dạng .xlsx)

Bước 3 — Ghép file để in

Mỗi lô là một file PDF liền mạch theo đúng thứ tự. In từng lô bằng một lệnh nên máy in không đảo trang; kẹt giấy thì chỉ in lại lô đó.

Bước 4 — In & tải về

Mở từng lô và in bằng một lệnh, in xong lô này mới in lô sau để xấp giấy không xen nhau. Bên dưới: lưu file mềm đã đổi tên.

MỚILưu file mềm: đổi tên file & tải về 1 file nén

Đổi tên từng file PDF theo cú pháp để gõ tìm nhanh trên máy. Số thứ tự trong tên trùng với số in ở góc bản giấy, file gốc giữ nguyên.
