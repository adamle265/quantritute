# Logo Quản trị tử tế – Phương án B (chốt 07/10/2026)

**Ý nghĩa:** la bàn = kim chỉ nam quản trị; mũi kim hướng Bắc là **con người** (chấm tròn là đầu, nửa kim vàng là thân) → "Quản trị lấy Con người làm gốc". Màu vàng hổ phách = ánh đèn của thương hiệu.

## Bảng màu
| Dùng cho | Nền sáng | Nền tối |
|---|---|---|
| Nét vòng + nửa kim dưới | `#231E19` (nâu mực) | `#ECE6DB` (kem) |
| Đầu + nửa kim trên | `#B06A22` (vàng hổ phách) | `#E8B06A` (vàng đèn) |
| Nền tối chuẩn | – | `#141210` |
| Câu định vị | `#6A6157` | `#B5AC9F` |

Chữ: **Lexend SemiBold** (tên thương hiệu), **IBM Plex Mono Medium** (câu định vị). Trong file SVG chữ đã chuyển thành nét vẽ, mở trên máy nào cũng đúng.

## File và cách dùng
| File | Dùng khi |
|---|---|
| `logo-ngang.svg` / `-2000.png` | Đầu tài liệu, slide, email, website trên nền sáng |
| `logo-ngang-nen-toi.svg` / `-2000.png` | Nền tối, video, ảnh bìa |
| `logo-mark.svg` / `-1024.png` | Biểu tượng riêng trên nền sáng (nền trong suốt) |
| `logo-mark-nen-toi.svg` / `-1024.png` | Biểu tượng trên nền tối (nền trong suốt) |

| `anh-dai-dien-kenh-800.png` | Ảnh đại diện YouTube / TikTok / Fanpage (an toàn khi bị cắt tròn) |
| `favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` | Biểu tượng tab trình duyệt (bản nét đậm riêng cho cỡ nhỏ; favicon.svg tự đổi màu theo chế độ sáng/tối của trình duyệt) |
| `apple-touch-icon.png` (180), `icon-512.png` | Biểu tượng khi lưu web ra màn hình điện thoại |

## Quy tắc
- Khoảng trống quanh logo tối thiểu bằng **đường kính chấm tròn "đầu" × 2**.
- Cỡ nhỏ nhất: biểu tượng **24px** (dưới mức đó dùng bản favicon nét đậm); logo ngang **cao 32px**.
- Không kéo méo, không đổi màu ngoài bảng trên, không thêm bóng đổ hay hiệu ứng phát sáng lên biểu tượng.
- Ảnh "Compass for the Kind" giữ làm **ảnh bìa / key visual**, không dùng thay logo.
