# 00 · TIẾN ĐỘ CHUNG – Dự án 5.0

> File chung cho **mọi hội thoại** làm việc trong folder `Dự án 5.0`. Mỗi hội thoại đọc file này khi bắt đầu và cập nhật khi xong một việc, để hội thoại sau nắm được tiến độ, yêu cầu và quyết định của anh Minh Tuấn.
> Bắt đầu dùng: 09/10/2026. Giờ ghi theo giờ Việt Nam (UTC+7).

## 1. Quy tắc cho mỗi hội thoại (bắt buộc)
1. **Đầu phiên:** đọc mục 2 → 5 của file này (không cần đọc nhật ký). Xem mục 2 để biết hội thoại khác đang sửa file nào. **Hội thoại làm video** chỉ đọc mục 2 rồi theo `Video xây kênh/00_BẮT ĐẦU VIDEO MỚI.md`. Nhật ký giữ 10 dòng mới nhất; dòng cũ hơn chuyển sang `00_LƯU TRỮ - Nhật ký cũ.md` (không cần đọc).
2. **Nhận việc:** thêm 1 dòng vào mục 2 "Đang làm" (tên hội thoại/việc, thư mục/file sẽ sửa, giờ bắt đầu). Nếu file cần sửa đang có hội thoại khác ghi tên → không sửa chồng; báo anh trước.
3. **Mỗi khi xong một mốc** (anh duyệt, giao file, đổi yêu cầu, có lệnh anh cần chạy): ghi ngay 1 dòng vào mục 6 "Nhật ký" (dòng mới ở TRÊN cùng) và cập nhật mục 3–5 nếu thay đổi.
4. **Kết thúc việc:** xoá dòng của mình ở mục 2, cập nhật trạng thái mục 3.
5. **Cách sửa file an toàn khi nhiều hội thoại cùng chạy:** đọc lại file ngay trước khi ghi; chỉ sửa đúng dòng/mục của mình (python đọc–sửa–ghi, chuỗi cũ phải khớp đúng 1 lần), không chép đè cả file từ bản đã đọc lâu trước đó; không xoá dòng của hội thoại khác.
6. Không ghi mật khẩu, khoá API, dữ liệu khách hàng thật vào file này.
7. Chi tiết kỹ thuật để ở README của từng phần (ví dụ `quantritute/cong-cu/<công cụ>/README.md`); file này chỉ ghi tóm tắt + đường dẫn.
8. **Tách file theo chủ đề (anh chốt 18/10):** nhật ký chi tiết của từng chủ đề ghi vào file riêng `00_TIẾN ĐỘ - <chủ đề>.md` (đang có: `00_TIẾN ĐỘ - Kênh video.md`, `00_TIẾN ĐỘ - Bộ công cụ Spa.md`); file chung này chỉ giữ mục 2–5 và 1 dòng tóm tắt mỗi mốc. **Không bao giờ ghi lại cả file từ bản đã đọc trước đó**: lấy bản mới nhất ngay trước khi ghi, chỉ chèn/sửa dòng của mình, rồi ghi ngay.
